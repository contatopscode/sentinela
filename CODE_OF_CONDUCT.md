# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) como código de conduta para todas as pessoas que participam de issues, pull requests, discussões e demais espaços do projeto.

Em resumo: seja respeitoso, acolha pontos de vista diferentes, aceite críticas construtivas e foque no que é melhor para a comunidade. Assédio, ataques pessoais e qualquer forma de discriminação não são tolerados.

## Como relatar

Comportamentos inaceitáveis podem ser relatados de forma privada aos mantenedores pelo relato privado do GitHub (aba **Security** → **Report a vulnerability**, indicando no título que se trata de conduta). Todos os relatos serão analisados com sigilo.
